# Working on agent-kit

This repo is public: no secrets, no personal or employer details, no private repo names. Personal facts belong in the user's `~/.agents/personal.md`, outside the repo.

- Tracker: GitHub issues and PRs in this repo.
- Skills follow the Agent Skills format; use the `writing-for-agents` skill when editing a skill or an `AGENTS.md`. A skill must read correctly in every environment, so it says "the tracker", never a specific tool.
- After changing anything, run the installer for this machine and check that every link in `~/.claude/skills` and `~/.agents/skills` resolves to a `SKILL.md`. Keep `install.ps1` and `install.sh` doing the same thing.
