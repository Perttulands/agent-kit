---
name: research
description: Research a question against primary sources and return cited findings. Use for documentation or API investigations and delegated reading work.
---

Delegate a bounded research question when useful work can continue here. Give
the worker the question, scope, output destination, and evidence required.
If you are already that worker, do the research yourself.

For project work, link the report from the owning issue or PR.
Standalone read-only research needs no issue.

1. Follow claims to their primary sources: official documentation, source
   code, specifications, or first-party data. Open and inspect the source;
   a search snippet is only a lead.
2. Separate verified facts, inferences, contradictions, and unanswered
   questions. Give enough provenance to check each material claim.
3. Deliver in the requested form and location. Otherwise write one Markdown
   report where the repository keeps research, or to a task-owned temporary
   file when no repository output is appropriate. Cite sources beside claims.

Finish when the report answers the bounded question or explains exactly what
missing evidence prevents an answer. A coordinator reads the report and checks
its decisive sources before relying on it.
